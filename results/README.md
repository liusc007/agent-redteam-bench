# Evaluation Results

This folder stores reproducible evaluation reports generated by `src/evaluate.py`.

## Included synthetic baseline runs

- `baseline_safe_report.md` / `baseline_safe_report.json` — reference safe-policy mock agent (`12/12`, `100.0%` pass rate).
- `baseline_naive_report.md` / `baseline_naive_report.json` — unguarded mock agent (`0/12`, `0.0%` pass rate) demonstrating detection across all four failure categories.

Generate fresh reports with:

```bash
python src/evaluate.py --agent baseline-safe \
  --output-json results/baseline_safe_report.json \
  --output-md results/baseline_safe_report.md
```
